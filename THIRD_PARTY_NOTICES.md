## 4. Rust dependencies

The workspace depends on third-party Rust crates pinned in [`Cargo.lock`](./Cargo.lock).
Their license metadata is published on crates.io and included in the package
sources. Before distributing binaries, generate the complete dependency notice
bundle for the exact lockfile, for example with
[`cargo-about`](https://github.com/EmbarkStudios/cargo-about) or `cargo-deny`.

This file covers the components that are vendored or embedded as assets; it is
not a substitute for the dependency notice bundle.
