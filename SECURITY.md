# Security Policy

## Reporting Security Issues

If you discover a potential security vulnerability in **kitty-pptx**, please do not open a public issue.

Instead, please send an email with the details, steps to reproduce, and any proof-of-concept files to:

**ahati@user.noreply.github.com**

Please include:
- A description of the issue and potential impact
- Affected version(s) or git commit hash
- Minimal reproducible sample file (e.g. malformed PPTX or PDF)
- Any proposed remediation

## Response Timeline

- **Initial acknowledgment**: Within 48 hours
- **Assessment and fix proposal**: Within 7 business days
- **Coordinated disclosure**: A patch and release advisory will be published once resolved.
